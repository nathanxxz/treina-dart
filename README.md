# Treina Dart

Repositório de estudos e prática em Dart.

Este projeto funciona como um caderno aberto de aprendizado: aqui ficam exemplos pequenos, exercícios resolvidos, anotações de evolução e uma trilha de desafios para continuar estudando.

## Para quem é este repositório

Este repositório pode ajudar quem:

- está começando em Dart;
- quer revisar fundamentos da linguagem;
- quer ver exemplos simples separados por assunto;
- quer uma lista de exercícios para praticar;
- quer acompanhar uma evolução real de estudos.

## Como executar os exemplos

Você precisa ter o Dart instalado.

Para verificar:

```bash
dart --version
```

Para rodar qualquer arquivo:

```bash
dart nome_do_arquivo.dart
```

Exemplos:

```bash
dart variaveis.dart
dart listasMapas.dart
dart estruturasCondicionais.dart
```

Alguns exemplos pedem entrada pelo terminal, como `estruturasCondicionais.dart`.

## Como contribuir ou continuar estudando

Para adicionar um novo exercício:

1. Escolha uma questão em [`README_EXERCICIOS_PROJETOS.md`](README_EXERCICIOS_PROJETOS.md).
2. Crie um arquivo `.dart` com nome claro.
3. Resolva primeiro de forma simples.
4. Rode o arquivo com `dart nome_do_arquivo.dart`.
5. Depois tente melhorar nomes, funções e organização.
6. Atualize este README se adicionar um novo assunto importante.

Mais detalhes estão em [`CONTRIBUTING.md`](CONTRIBUTING.md).
