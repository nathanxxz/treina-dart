# Treina Dart

Repositório criado para guardar meus estudos e exercícios de prática com a linguagem Dart.

A ideia é usar este espaço para testar conceitos básicos da linguagem, escrever pequenos exemplos e acompanhar minha evolução enquanto aprendo.

## Conteúdos praticados

- Variáveis e tipos primitivos
- Uso de `var`, `const` e `final`
- Listas, mapas e conjuntos
- Estruturas condicionais com `if`, `else if` e `else`
- Entrada de dados pelo terminal
- `switch` tradicional
- `switch expressions`

## Arquivos

| Arquivo | Descrição |
| --- | --- |
| `variaveis.dart` | Exemplos de tipos primitivos como `int`, `String`, `double`, `bool` e uso de variável nula com `String?`. |
| `constFinals.dart` | Prática com `var`, `const` e `final`. |
| `listasMapas.dart` | Exemplos usando `List`, `Map` e `Set`. |
| `estruturasCondicionais.dart` | Programa simples com leitura de nome e idade, validações, condicionais e `switch`. |
| `switchExpressions.dart` | Exemplo de `switch expression` para retornar mensagens de acordo com o dia da semana. |

## Como executar

Para rodar os arquivos, é necessário ter o Dart instalado na máquina.

Execute um exemplo com:

```bash
dart nome_do_arquivo.dart
```

Exemplo:

```bash
dart variaveis.dart
```

Alguns arquivos podem pedir entrada pelo terminal, como:

```bash
dart estruturasCondicionais.dart
```

## Objetivo

Este repositório serve como um caderno de prática para fixar fundamentos de Dart e registrar pequenos exercícios durante o aprendizado.
